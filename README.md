## Русский

### Описание :3

* Полный перевод всех диалогов
* Полный перевод интерфейса, меню паузы авторов и настроек

### Установка

#### Автоматическая установка:
1. Запустите файл `install.bat`
2. Скрипт автоматически найдёт путь к игре Drag'n Wash в библиотеке Steam и скопирует все необходимые файлы
3. Запустите игру через Steam

#### Ручная установка:
1. Откройте папку с установленной игрой (в Steam: ПКМ по Drag'n Wash > Управление > Просмотреть локальные файлы)
2. Скопируйте в корневую папку игры (рядом с `DragNWash.exe`):
   * файл `winhttp.dll`
   * файл `doorstop_config.ini`
   * папку `LocalizationMod` со всем её содержимым
3. Запустите игру. В главном меню нажмите на кнопку локализации под логотипом (справа) игры и выберите нужный язык

### Удаление

#### Автоматическое удаление:
1. Запустите файл `uninstall.bat`
2. Скрипт автоматически удалит файлы мода из папки игры

#### Ручное удаление:
1. Откройте папку с игрой
2. Удалите следующие файлы и папки:
   * `winhttp.dll`
   * `doorstop_config.ini`
   * папку `LocalizationMod`
3. Игра вернётся к исходному состоянию без изменений оригинальных файлов

## English

### Description :3

* Full translation of all dialogues
* Full translation of the interface, pause menu, credits and settings
* Translated menu button textures (new game, settings, exit, continue, save slots)
* Translated signs, wash bay posters and interactive notices
* Translated marker writings and dirt with dynamic texture baking
* Entrance sign localization Open/Closed
* Styled font with Cyrillic support matching the visual style of the game
* Quality selector for translated textures (standard and 2X high resolution)
* The entire localization was done completely manually by hand
* Unfortunately only Russian and Ukrainian languages are currently available in the mod, but anyone interested can view the code, use the templates, or take whatever they need to create their own translation
* Note: absolutely everything is translated, except animations, unfortunately <:(

### Installation

#### Automatic Installation:
1. Run `install.bat`
2. The script will automatically find the Drag'n Wash path in your Steam library and copy all required files
3. Launch the game via Steam

#### Manual Installation:
1. Open the folder with the installed game (in Steam: Right-click Drag'n Wash > Manage > Browse local files)
2. Copy to the game root folder (next to `DragNWash.exe`):
   * file `winhttp.dll`
   * file `doorstop_config.ini`
   * folder `LocalizationMod` with all its contents
3. Launch the game. In the main menu, click the localization button below the title (on the right) and select the desired language

### Uninstallation

#### Automatic Uninstallation:
1. Run `uninstall.bat`
2. The script will automatically delete mod files from the game folder

#### Manual Uninstallation:
1. Open the game folder
2. Delete the following files and folders:
   * `winhttp.dll`
   * `doorstop_config.ini`
   * folder `LocalizationMod`
3. The game will return to its original state without modifying original files
